# Leads & Clients

This folder contains markdown files for managing leads and clients information.

## Structure

- Individual client/lead files should be named using the format: `{client-name}.md`
- Use consistent naming conventions (lowercase, hyphens for spaces)
- Include relevant contact information, project details, and communication history

## Template

```markdown
# Client Name

## Contact Information
- **Name**: 
- **Email**: 
- **Phone**: 
- **Company**: 

## Project Details
- **Project Type**: 
- **Status**: 
- **Start Date**: 
- **Last Contact**: 

## Notes
- 
```
